# Autos Colombia🚘

## Descripción

Sistema de información desarrollado para el parqueadero Autos Colombia como parte de la actividad Evidencia de Aprendizaje 1. Diseño Sistema de Información – Iteración 1.

El sistema permite:

- Registrar vehículos.
- Registrar entradas de vehículos.
- Asignar celdas disponibles.
- Visualizar los registros realizados.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
