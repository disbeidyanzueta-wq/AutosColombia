# Autos Colombia 🚘

## Descripción

Sistema de información desarrollado para el parqueadero Autos Colombia como parte de las actividades académicas del curso de Ingeniería de Software.

El proyecto se desarrolla por iteraciones, permitiendo gestionar de manera progresiva las operaciones del parqueadero.

## Iteración 1

### Gestión de entrada y salida de vehículos

- Registrar vehículos.
- Registrar entradas de vehículos.
- Asignar celdas disponibles.
- Registrar salidas de vehículos.
- Consultar historial de movimientos.
- Generar reportes.

## Iteración 2

### Gestión de usuarios y gestión de celdas

- Registrar usuarios.
- Consultar usuarios.
- Actualizar usuarios.
- Eliminar usuarios.
- Gestionar roles.
- Registrar celdas.
- Consultar celdas.
- Actualizar celdas.
- Eliminar celdas.
- Visualizar disponibilidad de celdas.
- Consultar historial de celdas.
